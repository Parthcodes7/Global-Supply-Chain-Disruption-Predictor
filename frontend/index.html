📊 Academic Relational Views (02_views.sql)

Standard SQL Views creating pre-computed security and disruption perspectives

1. v_disrupted_shipments

Filters shipments in ('Disrupted', 'Delayed', 'Diverted') status, joining origin and destination ports with commodity pricing.

SELECT * FROM v_disrupted_shipments;
2. v_high_risk_ports

Left joins PORTS with CONFLICTS where port status is 'Hazard Alert' or country instability score ≥ 70.0.

SELECT * FROM v_high_risk_ports;
3. v_commodity_exposure

Aggregates disrupted financial value grouped by commodity using SUM(), AVG(), and COUNT().

SELECT * FROM v_commodity_exposure;

⚡ Test MySQL Trigger: trg_after_disaster_insert

When a disaster record is inserted into DISASTERS, MySQL's trigger automatically computes spherical distances (ST_Distance_Sphere), updates nearby ports to Hazard Alert, marks active shipments as Disrupted, and writes audit records to DISRUPTION_LOG.
